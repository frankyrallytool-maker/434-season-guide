# 434 Season Guide

Responsive static website for an interactive Dark War Survival season guide.

## Files
- `index.html` — page structure and validated guide content
- `styles.css` — responsive desktop/mobile design
- `app.js` — accordion navigation, mobile menu and local progress tracking

## Publish with GitHub Pages
The site is fully static and deployed with GitHub Pages from the `main` branch.

## Content status
V1 includes the five validated opening actions:
1. Enter the new season map
2. Hunt Boomers & Zombies
3. Build the Altar & Obelisk
4. Use the Shadow Call reset
5. Start Ruins Tasks and read buff details carefully

Detailed Ruins limits, refresh costs and additional season mechanics should only be added after verification.
